
  # FAIR2WISE Prototype UI

  This is a code bundle for FAIR2WISE Prototype UI. The original project is available at https://www.figma.com/design/T9NVvtM32izcjlF4mmT3vD/FAIR2WISE-Prototype-UI.

  ## Running the code

  Run `npm i` to install the dependencies.

  Start the FAIR2WISE agent API from the `f2wlocal` repo:

  ```bash
  cd /Users/mateo/Desktop/f2wlocal
  ./scripts/start_agent_backend.sh
  ```

  Run the UI against that API:

  ```bash
  cd /Users/mateo/Desktop/f2wlocal
  ./scripts/start_agent_frontend.sh
  ```
